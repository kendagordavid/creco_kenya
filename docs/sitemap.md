# CRECO PBO Platform — Sitemap

ToR Deliverable #2 · UI/UX wireframes · Week 2

This sitemap maps every wireframe screen to the five platform modules defined in the CRECO Kenya Terms of Reference. Wireframes are viewable at [`wireframes/index.html`](../wireframes/index.html).

## Platform modules (ToR)

| # | Module | Wireframe screens |
|---|--------|-------------------|
| 1 | Legal awareness / Knowledge hub | WF-10 – WF-16 |
| 2 | Compliance tools | WF-20 – WF-26 |
| 3 | Guided Q&A | WF-30 – WF-33 |
| 4 | Civic space monitoring | WF-40 – WF-46 |
| 5 | Admin dashboard & CMS | WF-50 – WF-61 |

## User roles

| Role | Access |
|------|--------|
| Public visitor | Home, Knowledge, Compliance (basic), Guidance, Search, Login/Register |
| Registered PBO user | All public + Monitoring, My submissions, Saved assessments, Profile |
| Content editor | CMS dashboard, Article editor, FAQ manager, Media library |
| Moderator | Dashboard, Submissions queue, Q&A flags, Approve/reject |
| Administrator | All staff areas + User management, Settings, Export, MFA |
